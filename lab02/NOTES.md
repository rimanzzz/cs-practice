Git и GitHub — это два тесно связанных, но принципиально разных инструмента в работе разработчика. Git — это система контроля версий, а GitHub — онлайн-платформа, которая использует Git. git status
«Использованные команды»
git status Эта команда показывает текущее состояние репозитория: какие файлы изменены, какие подготовлены к коммиту, а какие вообще не отслеживаются Git.
git diff Эта команда сравнивает два набора данных и выводит разницу в виде патча (diff).
git diff --staged Эта команда сравнивает индекс (подготовленные изменения) с последним коммитом (HEAD). То есть она показывает, что именно войдёт в следующий коммит.
"Ветки"
ветка — это последовательность коммитов, упорядоченных по времени.
