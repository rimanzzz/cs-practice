git diff — показывает различия между версиями (например, между рабочей директорией и коммитом).
git show — выводит детали одного коммита (метаданные и изменения).
git log — отображает историю коммитов.
git log -S <строка> — ищет коммиты, где изменилось число вхождений строки.
git blame <файл> — показывает, какой коммит и кто последний раз менял каждую строку файла.
git restore file — отменяет git add для файла: правки остаются в файле, убираются из индекса.
git restore --source=HEAD file — перезаписывает файл версией из последнего коммита: все правки теряются.
git restore --source=HEAD --staged file — убирает изменения только из индекса, в файле правки сохраняются.
Проще говоря: без --source команда работает с индексом, с --source — берёт конкретную версию из истории и может затереть правки.
